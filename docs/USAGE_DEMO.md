## 实际使用技巧

### 技巧1: 根据PDF质量选择

```
清晰的文本PDF → 选择 Gemini (更快)
   ↓
扫描件/拍照   → 选择 Qwen VL (更准确)
   ↓
复杂版面     → 选择 Qwen VL (识别更好)
```

### 技巧2: 批量导入建议

1. **小批量测试**: 先用1-2份试卷测试不同模型
2. **记录结果**: 对比哪个模型效果更好
3. **批量处理**: 用效果好的模型处理剩余文件

### 技巧3: 处理失败时

```
第1次尝试: Gemini
   ↓ 失败
第2次尝试: Qwen VL
   ↓ 失败
第3次尝试: 检查PDF文件质量，尝试重新扫描
```

### 技巧4: 成本优化

如果你有API配额限制：

1. **优先用免费额度高的模型** (如Gemini)
2. **重要文件用准确率高的模型** (如Qwen VL)
3. **定期检查API使用量**

## API调用示例

### JavaScript/TypeScript

```typescript
// 获取可用模型
const response = await fetch('/api/papers/models', {
  headers: {
    'Authorization': `Bearer ${token}`
  }
});
const { models } = await response.json();

// 使用指定模型解析
const formData = new FormData();
formData.append('file', pdfFile);
formData.append('model', 'qwen-vl');  // 或 'gemini'

const parseResponse = await fetch('/api/papers/parse', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${token}`
  },
  body: formData
});
```

### Python

```python
import requests

# 获取可用模型
response = requests.get(
    'http://localhost:8080/api/papers/models',
    headers={'Authorization': f'Bearer {token}'}
)
models = response.json()['models']

# 使用指定模型解析
with open('test.pdf', 'rb') as f:
    files = {'file': f}
    data = {'model': 'qwen-vl'}
    response = requests.post(
        'http://localhost:8080/api/papers/parse',
        headers={'Authorization': f'Bearer {token}'},
        files=files,
        data=data
    )
```

### curl

```bash
# 获取可用模型
curl -X GET http://localhost:8080/api/papers/models \
  -H "Authorization: Bearer YOUR_TOKEN"

# 使用Qwen VL解析
curl -X POST http://localhost:8080/api/papers/parse \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "file=@test.pdf" \
  -F "model=qwen-vl"
```

## 常见问题解答

### Q: 我应该选择哪个模型？

**A**: 
- 清晰的PDF → Gemini (更快)
- 中文试卷/扫描件 → Qwen VL (更准确)
- 不确定 → 都试试，看哪个效果好

### Q: 可以同时使用多个模型吗？

**A**: 不可以在一次导入中同时使用。但你可以：
1. 用A模型导入一次
2. 删除结果
3. 用B模型再导入一次
4. 对比效果

### Q: 模型选择会影响导入速度吗？

**A**: 会。一般来说：
- Gemini: 30秒-1分30秒
- Qwen VL: 45秒-1分30秒
具体取决于PDF大小和复杂度

### Q: 如果选错模型了怎么办？

**A**: 可以：
1. 在预览阶段放弃导入
2. 重新上传并选择其他模型
3. 或者导入后在管理页面删除，重新导入

### Q: 所有模型都显示"未配置"？

**A**: 需要在 `backend/.env` 配置至少一个API Key，然后重启后端。

---

**提示**: 建议在生产使用前，用测试数据对比不同模型的效果，选择最适合你的场景的模型。
